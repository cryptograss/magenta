Wiki hooks

What happens here when a page changes on PickiPedia. PickiPedia pushes each save to /api/wiki/hook/; a sweep once a minute is the check on the push, and both run the same hooks. Any other page changed is forgotten, and read again when next asked for. A hook that fails is a line in #ops.
