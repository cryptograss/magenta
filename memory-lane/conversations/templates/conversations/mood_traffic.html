A visit is someone heard again after half an hour's quiet. People, crawlers and ours are told apart by the name the browser gives itself, so a crawler that lies is counted as a person. Links followed are within the site itself: a click out to somewhere else is invisible to a server, and the only way to see one would be a script in the reader's browser, which we don't do. Left out on purpose: addresses (a visitor is a number made with a salt that changes daily), anything in a query string that isn't the page's name, and what anyone typed into a search engine. The counts are roles/goaccess in maybelle-config.
