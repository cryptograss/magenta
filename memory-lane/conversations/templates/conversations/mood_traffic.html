A visit is someone heard again after half an hour's quiet. Only a browser is counted as a person: every browser says so in its user agent, and a program that fetches a page says something else or says nothing. A scraper that sends a browser's user agent is counted as a person all the same, and no log can tell the difference — but it shows up by name under who asked. Links followed are within the site itself: a click out to somewhere else is invisible to a server, and the only way to see one would be a script in the reader's browser, which we don't do. Left out on purpose: addresses (a visitor is a number made with a salt that changes daily), anything in a query string that isn't the page's name, and what anyone typed into a search engine. The counts are roles/goaccess in maybelle-config.
